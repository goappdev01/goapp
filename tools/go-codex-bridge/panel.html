Conexión OAuth con Trello

En Trello → Tus aplicaciones → GO Puente Codex → OAuth 2.0, conserva Confidential, añade o confirma la URL de retorno http://localhost:8765/trello/callback y activa read:board:trello y write:board:trello. Pulsa Save / Guardar. El permiso offline_access lo solicita este puente al conectar; no aparece en esa tabla.


Utiliza el ID del cliente OAuth 2.0, no el nombre GO Puente Codex, el ID de la aplicación ni la API key de Trello Auth. Los secretos se introducen únicamente aquí y se guardan cifrados para este usuario de Windows.




La escritura OAuth no autoriza modificar cualquier tarjeta. Este panel te mostrará la operación exacta antes de enviarla.
